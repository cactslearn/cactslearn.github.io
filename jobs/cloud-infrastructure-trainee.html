Cloud & AWS Infrastructure Trainee

Assist cloud architects in configuring AWS EC2 instances, S3 storage buckets, VPC virtual networks, and IAM security policies.

Key Responsibilities & Tasks

  • Provision and monitor AWS EC2 servers, S3 buckets, and CloudWatch alarms.
  • Configure IAM user policies, security groups, and VPC subnet routing.
  • Write basic shell scripts for cloud server maintenance and backups.

Required Skills & Qualifications

  • Understanding of basic Linux terminal commands and networking principles.
  • Foundational knowledge of AWS cloud services (EC2, S3, IAM).
  • Interest in cloud security and architecture.
