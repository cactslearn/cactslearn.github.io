Cybersecurity & SOC Analyst Trainee

Monitor security logs, conduct vulnerability assessments, and assist in SOC threat detection across network ports.

Key Responsibilities & Tasks

  • Analyze network packet captures using Wireshark and Nmap scanning tools.
  • Conduct basic vulnerability scans and document security remediation steps.
  • Assist in configuring firewall rules and reviewing security logs.

Required Skills & Qualifications

  • Foundational understanding of TCP/IP networking, OSI layers, and ports.
  • Knowledge of basic Linux/Windows security commands.
  • Interest in ethical hacking, penetration testing, and SOC analysis.
