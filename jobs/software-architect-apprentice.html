Junior Software Architect Apprentice

Assist senior architects in designing microservice patterns, evaluating database trade-offs, and documenting system blueprints.

Key Responsibilities & Tasks

  • Create UML architecture diagrams, sequence charts, and API specs.
  • Evaluate database caching strategies (Redis, Memcached) and queue systems.
  • Participate in high-level system design reviews for enterprise projects.

Required Skills & Qualifications

  • Background in software engineering or computer science.
  • Understanding of OOP, microservices, and web protocols.
  • Passion for scalable software design and architecture patterns.
