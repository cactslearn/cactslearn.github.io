Detailed Syllabus

Below is the comprehensive, module-by-module curriculum. As this training is strictly 1-to-1, we can adjust the syllabus scope or spend more time on specific modules based on your learning speed.

Course Prerequisites

Basic understanding of Linux command-line operations and Git concepts.

Full Curriculum Structure

Module 1: Linux Operations & Version Control

3 Weeks
  • Linux directory structures, permissions, and shell scripting
  • Git commands, branch workflows, and remote repository syncing
  • Package management and system services administration

Module 2: Containerization with Docker

3 Weeks
  • Writing Dockerfiles to build customized application containers
  • Managing Docker volumes, networks, and environment variables
  • Multi-container deployments with Docker Compose

Module 3: Kubernetes Orchestration & Ansible Automation

3 Weeks
  • Deploying Kubernetes pods, services, and replica sets
  • Writing Ansible playbooks for automated server configurations
  • Managing secrets and environment configurations

Module 4: CI/CD Pipelines & Real Deployment

3 Weeks
  • Configuring Jenkins / GitHub Actions pipelines for auto-builds
  • Deploying containerized code to remote server nodes
  • Active infrastructure configuration for live company projects

Tools & Technologies Mastered

DockerKubernetesJenkinsAnsibleLinux (Ubuntu)Git & GitHub

You will gain hands-on operational capability in these tools during screenshare coding loops, creating real repositories.

Hands-on Lab Assignments & Projects

  • Project 1: Writing Dockerfiles to containerize a web application.
  • Project 2: Configuring a Jenkins CI/CD pipeline for automated test builds.
  • Project 3: Deploying a multi-container app cluster using Kubernetes.
  • Project 4: Automated server deployment using Ansible playbook.
