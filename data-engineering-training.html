Course FAQs

What is the difference between Data Science and Data Engineering?

+

Data Science focuses on analyzing data and building predictive models. Data Engineering focuses on building the systems, data pipelines, and infrastructure that store and move that data.

Do we write code in Apache Spark?

+

Yes. We use PySpark (Spark with Python) to write distributed data manipulation processes.
