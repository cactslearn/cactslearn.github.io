Curriculum Outline

This curriculum is fully customized for you. We adapt the pace based on your learning speed. Our trainers work 1-to-1, detailing every line of code.

Module 1: Descriptive & Inferential Statistics

3 Weeks
  • Central tendency, dispersion, probability distributions
  • Hypothesis testing, p-values, A/B testing principles
  • Sampling techniques and statistical errors

Module 2: Python Data Pipeline

4 Weeks
  • Data collection, cleaning, and preprocessing with Pandas
  • Dealing with missing values and outliers
  • Exploratory Data Analysis (EDA) best practices

Module 3: Structured Querying & Warehousing

3 Weeks
  • Relational database querying with SQL (joins, subqueries, aggregates)
  • Connecting Python to SQL databases
  • Data schema design for analytics

Module 4: Predictive Modeling & Case Projects

4 Weeks
  • Linear and logistic regression implementations
  • Building business dashboards and storyboards
  • Analyzing actual company datasets during the live internship phase
